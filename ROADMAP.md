# Roadmap

## Current prototype

- [x] Smartphone/USB/video acquisition interface
- [x] Interactive frozen-frame segmentation
- [x] GrabCut and optional MobileSAM backends
- [x] Pixel inspection and known-height distance calculation
- [x] Calibration CLI and local experiment records
- [x] Offline synthetic regression tests
- [ ] Validate the refactor on the author's live phone setup
- [ ] Repeat independent physical measurements with recorded calibration

## Next research and implementation steps

- [ ] Continuous ping pong ball detection/tracking
- [ ] Camera geometry and trajectory estimation appropriate to a moving ball
- [ ] Choose and bench-test a microcontroller
- [ ] Pan-tilt and launcher control interface
- [ ] Mechanical assembly and safe, bounded actuator tests
- [ ] Connect perception, decision making and controller commands

No board choice or completed ball-playing capability is implied by this roadmap.
